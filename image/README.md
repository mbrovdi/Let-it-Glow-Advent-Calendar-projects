## Image Folder

This folder stores images used by the project, such as:

- Circuit photos
- Wiring diagrams
- Build progress snapshots
- Reference visuals for README files

### Recommended Naming

Use clear file names so images are easy to find later:

- `day-02-led-blink.jpg`
- `day-03-button-input-wiring.png`
- `day-04-bar-graph-circuit.jpg`

### Tips

- Prefer `.png` for diagrams and `.jpg` for photos
- Keep image names lowercase and use hyphens
- Add or update image links in each day README when new images are added
