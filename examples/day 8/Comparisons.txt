# Day 8 - Arduino vs Raspberry Pi Pico: 12-LED RGB Ring Comparisons

This file compares Day 8 activities using the 12-LED addressable RGB ring on the Raspberry Pi Pico (MicroPython) and Arduino MKR Zero (C++/Arduino language).

---

## Hardware Setup

| Feature | Raspberry Pi Pico | Arduino MKR Zero |
|---|---|---|
| LED ring type | 12x addressable RGB LEDs | 12x addressable RGB LEDs |
| Data IN pin | GPIO2 (physical pin 4) | D2 |
| Power | VBUS 5V (physical pin 40) | 5V |
| Ground | GND (for example physical pin 3) | GND |
| Number of LEDs | 12 | 12 |
| Library | neopixel | Adafruit_NeoPixel |

Note: Day 8 ring examples use RGB order in the lesson material.

---

## Activity 1: Single LED Control

### Raspberry Pi Pico (MicroPython)

```python
from machine import Pin
from neopixel import NeoPixel

ring = NeoPixel(Pin(2), 12)

ring[0] = (10, 0, 0)
ring.write()
```

### Arduino MKR Zero (C++)

```cpp
#include <Adafruit_NeoPixel.h>

Adafruit_NeoPixel ring(12, 2, NEO_RGB + NEO_KHZ800);

void setup() {
	ring.begin();
	ring.clear();
	ring.setPixelColor(0, ring.Color(10, 0, 0));
	ring.show();
}

void loop() {
}
```

### Key Differences

| Concept | MicroPython (Pico) | Arduino (C++) |
|---|---|---|
| Ring setup | `NeoPixel(Pin(2), 12)` | `Adafruit_NeoPixel(12, 2, ...)` |
| Set one LED | `ring[0] = (r,g,b)` | `setPixelColor(0, Color(r,g,b))` |
| Push data to LEDs | `ring.write()` | `ring.show()` |

---

## Turn Everything Off

### Pico

```python
ring.fill((0, 0, 0))
ring.write()
```

### Arduino

```cpp
ring.clear();
ring.show();
```

## Activity 2: Multiple LEDs

### Raspberry Pi Pico (direct indexing)

```python
from machine import Pin
from neopixel import NeoPixel
import time

ring = NeoPixel(Pin(2), 12)
ring.fill((0, 0, 0))
ring.write()
time.sleep(1)

ring[0] = (0, 0, 10)
ring[3] = (0, 0, 10)
ring[6] = (0, 0, 10)
ring[9] = (0, 0, 10)
ring.write()
```

### Raspberry Pi Pico (list + loop)

```python
myleds = [0, 3, 6, 9]

for i in myleds:
	ring[i] = (0, 0, 10)
	ring.write()
```

### Arduino MKR Zero (array + loop)

```cpp
#include <Adafruit_NeoPixel.h>

Adafruit_NeoPixel ring(12, 2, NEO_RGB + NEO_KHZ800);
int myleds[] = {0, 3, 6, 9};

void setup() {
	ring.begin();
	ring.clear();
	ring.show();
	delay(1000);

	for (int i = 0; i < 4; i++) {
		ring.setPixelColor(myleds[i], ring.Color(0, 0, 10));
	}
	ring.show();
}

void loop() {
}
```

### Key Differences

| Concept | MicroPython (Pico) | Arduino (C++) |
|---|---|---|
| LED collection | Python list | C++ array |
| Loop syntax | `for i in myleds:` | `for (int i = 0; i < 4; i++)` |

## Activity 3: Add Delay for Sequenced Effect

### Pico

```python
for i in myleds:
	ring[i] = (0, 0, 10)
	ring.write()
	time.sleep(1)
```

### Arduino

```cpp
for (int i = 0; i < 4; i++) {
	ring.setPixelColor(myleds[i], ring.Color(0, 0, 10));
	ring.show();
	delay(1000);
}
```

### Key Differences

| Concept | MicroPython (Pico) | Arduino (C++) |
|---|---|---|
| Delay function | `time.sleep(seconds)` | `delay(milliseconds)` |
| Sequential visual update | One LED per loop then wait | Same logic, ms timing |

## Activity 4: Spinning Lights (while True)

### Pico

```python
from machine import Pin
from neopixel import NeoPixel
import time

ring = NeoPixel(Pin(2), 12)
myleds = [0, 3, 6, 9]

ring.fill((0, 0, 0))
ring.write()
time.sleep(1)

while True:
	for i in myleds:
		ring[i] = (0, 0, 10)
		ring.write()
		time.sleep(0.3)
		ring.fill((0, 0, 0))
		ring.write()
```

### Arduino

```cpp
#include <Adafruit_NeoPixel.h>

Adafruit_NeoPixel ring(12, 2, NEO_RGB + NEO_KHZ800);
int myleds[] = {0, 3, 6, 9};

void setup() {
	ring.begin();
	ring.clear();
	ring.show();
	delay(1000);
}

void loop() {
	for (int i = 0; i < 4; i++) {
		ring.setPixelColor(myleds[i], ring.Color(0, 0, 10));
		ring.show();
		delay(300);
		ring.clear();
		ring.show();
	}
}
```

### Key Differences

| Concept | MicroPython (Pico) | Arduino (C++) |
|---|---|---|
| Infinite loop | `while True:` | `loop()` repeats automatically |
| Clear ring each step | `fill((0,0,0))` | `clear()` |

## Activity 5: Bouncing Lights (forward + reverse)

### Pico

```python
from machine import Pin
from neopixel import NeoPixel
import time

ring = NeoPixel(Pin(2), 12)
ring.fill((0, 0, 0))
ring.write()
time.sleep(1)

while True:
	for i in range(12):
		ring[i] = (5, 0, 5)
		ring.write()
		time.sleep(0.09)
		ring.fill((0, 0, 0))
		ring.write()

	for i in reversed(range(12)):
		ring[i] = (5, 0, 5)
		ring.write()
		time.sleep(0.09)
		ring.fill((0, 0, 0))
		ring.write()
```

### Arduino

```cpp
#include <Adafruit_NeoPixel.h>

Adafruit_NeoPixel ring(12, 2, NEO_RGB + NEO_KHZ800);

void setup() {
	ring.begin();
	ring.clear();
	ring.show();
	delay(1000);
}

void loop() {
	for (int i = 0; i < 12; i++) {
		ring.setPixelColor(i, ring.Color(5, 0, 5));
		ring.show();
		delay(90);
		ring.clear();
		ring.show();
	}

	for (int i = 11; i >= 0; i--) {
		ring.setPixelColor(i, ring.Color(5, 0, 5));
		ring.show();
		delay(90);
		ring.clear();
		ring.show();
	}
}
```

### Key Differences

| Concept | MicroPython (Pico) | Arduino (C++) |
|---|---|---|
| Reverse iteration | `reversed(range(12))` | `for (int i = 11; i >= 0; i--)` |
| Range end | 0..11 | 0..11 |

## Activity 6: Spinning Wheel of Colour

### Pico

```python
from machine import Pin
from neopixel import NeoPixel
import time
import random

ring = NeoPixel(Pin(2), 12)
ring.fill((0, 0, 0))
ring.write()
time.sleep(1)

while True:
	r = random.randint(0, 100)
	g = random.randint(0, 100)
	b = random.randint(0, 100)

	for i in range(12):
		ring[i] = (r, g, b)
		ring.write()
		time.sleep(0.05)
		ring.fill((0, 0, 0))
		ring.write()
```

### Arduino

```cpp
#include <Adafruit_NeoPixel.h>

Adafruit_NeoPixel ring(12, 2, NEO_RGB + NEO_KHZ800);

void setup() {
	ring.begin();
	ring.clear();
	ring.show();
	delay(1000);
	randomSeed(analogRead(A0));
}

void loop() {
	int r = random(0, 101);
	int g = random(0, 101);
	int b = random(0, 101);

	for (int i = 0; i < 12; i++) {
		ring.setPixelColor(i, ring.Color(r, g, b));
		ring.show();
		delay(50);
		ring.clear();
		ring.show();
	}
}
```

### Full-colour version tip

To fill the whole ring as the pattern advances, remove the ring-clear lines inside the inner loop.

## Activity 7: Double Random Ring

### Pico

```python
from machine import Pin
from neopixel import NeoPixel
import time
import random

ring = NeoPixel(Pin(2), 12)
ring.fill((0, 0, 0))
ring.write()
time.sleep(1)

while True:
	randomled = random.randint(0, 11)
	r = random.randint(0, 50)
	g = random.randint(0, 50)
	b = random.randint(0, 50)

	ring[randomled] = (r, g, b)
	ring.write()
	time.sleep(0.05)
	ring.fill((0, 0, 0))
	ring.write()
```

### Arduino

```cpp
#include <Adafruit_NeoPixel.h>

Adafruit_NeoPixel ring(12, 2, NEO_RGB + NEO_KHZ800);

void setup() {
	ring.begin();
	ring.clear();
	ring.show();
	delay(1000);
	randomSeed(analogRead(A0));
}

void loop() {
	int randomled = random(0, 12);
	int r = random(0, 51);
	int g = random(0, 51);
	int b = random(0, 51);

	ring.setPixelColor(randomled, ring.Color(r, g, b));
	ring.show();
	delay(50);
	ring.clear();
	ring.show();
}
```

### Key Differences

| Concept | MicroPython (Pico) | Arduino (C++) |
|---|---|---|
| Random LED index | `randint(0, 11)` | `random(0, 12)` |
| Random color range | `randint(0, 50)` | `random(0, 51)` |

## General Language Comparison: Day 8 Concepts

| Concept | MicroPython (Pico) | Arduino (C++) |
|---|---|---|
| Ring init | `NeoPixel(Pin(2), 12)` | `Adafruit_NeoPixel(12, 2, NEO_RGB + NEO_KHZ800)` |
| Set one pixel | `ring[i] = (r,g,b)` | `setPixelColor(i, Color(r,g,b))` |
| Update LEDs | `ring.write()` | `ring.show()` |
| Clear all LEDs | `fill((0,0,0))` | `clear()` |
| Forward loop | `for i in range(12)` | `for (int i = 0; i < 12; i++)` |
| Reverse loop | `for i in reversed(range(12))` | `for (int i = 11; i >= 0; i--)` |
| Infinite looping | `while True:` | `loop()` |
| Delay | `time.sleep(seconds)` | `delay(milliseconds)` |
| Random integer | `random.randint(a, b)` inclusive | `random(a, b)` upper bound excluded |

---

This comparison gives a direct translation path for Day 8 RGB ring patterns between Pico MicroPython and Arduino C++.
